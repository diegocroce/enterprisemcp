Methodology

Every entry links to a verified GitHub repo or vendor documentation page. GitHub stars, last push date, license and archived status come from the GitHub API (refreshed by scripts/refresh). Auth, access and hosting come from READMEs and vendor docs. Anything we could not verify is recorded as "unknown" and scores 0 for that criterion — a low score can mean "undocumented", not "bad".
