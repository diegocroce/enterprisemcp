# EnterpriseMCP

Rated directory of enterprise MCP servers. Live: https://diegocroce.github.io/enterprisemcp/

- `data/servers.json` — dataset
- `scripts/seed.py`, `scripts/refresh`, `scripts/score.py` — data + scoring
- `site/build.py` — static generator (`python3 site/build.py` -> `site/dist`)

The built site is published from the `gh-pages` branch.
